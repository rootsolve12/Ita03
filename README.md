# Wireless Ad Hoc Network (MANET) — UI/UX Design

A UI/UX design project focused on explaining **Wireless Ad Hoc Networks (MANETs)** through an interactive, screen-based educational presentation designed in **Figma**.

The project visualizes the key concepts, characteristics, and challenges of MANETs using a structured interface, interconnected screens, and interactive navigation.

## Overview

A Mobile Ad Hoc Network (MANET) is a wireless network consisting of mobile devices that communicate with one another without relying on fixed network infrastructure. Each node can act as both a host and a router, forwarding data for other nodes when required.

This project presents the fundamental concepts of MANETs through a visual learning experience, making networking topics easier to explore and understand.

## Objectives

- Design an intuitive and visually consistent educational interface.
- Explain the fundamental characteristics of wireless ad hoc networks.
- Present MANET challenges through organized content screens.
- Create an interactive prototype with connected screens and navigation flows.
- Improve the presentation of technical information through visual hierarchy and structured layouts.

## Features

- **Interactive prototype:** Navigate between screens using connected flows.
- **Educational content:** Explore MANET concepts and networking challenges.
- **Topic-based navigation:** Access individual topics through interactive links.
- **Consistent visual design:** Dark backgrounds, purple panels, magenta headings, and light-blue connectors.
- **Flowchart-based navigation:** Visualize relationships between screens and content sections.
- **Responsive design considerations:** Organize content for clear presentation across different screen sizes.

## Topics Covered

The project explores the following MANET concepts:

1. Introduction to Wireless Ad Hoc Networks
2. Characteristics of MANETs
3. Dynamic Topology
4. Limited Bandwidth and Energy Constraints
5. Routing Protocols
6. Security Concerns
7. Quality of Service (QoS) Provisioning
8. Scalability
9. Resource Management
10. Topology Control
11. Interference and Channel Access
12. Mobility Management

## Tools and Technologies

## Design and Navigation

The interface is organized into interconnected screens:

- **Introduction:** Presents the Wireless Ad Hoc Network concept.
- **Overview:** Illustrates the network structure and core characteristics.
- **Challenges:** Provides a central navigation point for exploring MANET challenges.
- **Detailed Topics:** Explains routing, security, QoS, topology, and resource constraints.
- **Conclusion:** Summarizes the key concepts and design challenges.

The Figma prototype uses connected navigation flows to let users move between the introduction, overview, and detailed topic screens.
